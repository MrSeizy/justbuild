# Video demos

[Back to the README](../../README.md) · [User guide](../user-guide.md)

These 24 JustBuild 0.1.0 recordings show Minecraft screens, wand clicks, previews, and block placement.
Each clip has instructional captions. Gold outlines identify panel controls; in-world preview controls turn yellow
in [brackets] when aimed at.

Planning and connection tests use fixed example responses from a local test service. The clips demonstrate
controls and workflow; they do not measure model quality or generation speed. No AI account was used.
