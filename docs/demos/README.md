# Demo videos

[Back to the README](../../README.md) · [User guide](../user-guide.md)

These JustBuild 0.1.0 recordings show actual Minecraft screens, wand clicks, previews, and block placement in disposable
worlds. Planning and connection tests use fixed example responses and token reports from a loopback HTTP endpoint.
The clips demonstrate controls and workflow; they do not measure model quality or generation speed. No AI account is used.

Clips 22 and 23 connect to a real local dedicated server. Clip 23 uses a server-side simulated collaborator to exercise
project permissions, material edits, and that player's own undo. It does not show a second live player's client UI.

The clips are H.264 MP4s hosted on GitHub. Watch them using the links below.
Each frame includes an instructional caption; gold outlines identify the relevant panel controls, and the in-world
preview controls turn yellow in [brackets] when aimed at.

The same run captures screenshots for the README and guides in [`docs/images/`](../images/). They cover the wand
HUD, in-world corner relocation, polygon footprint, [finished cottage](../images/cottage-build.png), before/after
comparison, workshop, requirements, named parts, version history, schematic export/import, and AI usage.
Additional screenshots show [profile checks](../images/profile-test.png), the [prompt editor](../images/prompt-editor.png),
[undo confirmation](../images/confirm-undo.png), [interior planning](../images/interior-planning.png),
[route checks](../images/walkability.png), [multiplayer response review](../images/multiplayer-response-review.png),
and the [in-world preview controls](../images/in-world-preview-controls.png).

discards it; clip 16 confirms restoration of the original checkpoint. Clips 17 and 21 demonstrate the requirements
and usage controls that previously had still screenshots only.

It verifies that moving and discarding leave the world unchanged, then shows the cottage being placed.
